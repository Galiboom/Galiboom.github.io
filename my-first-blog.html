首个开源项目：GaLi-Link

既然是第一篇博客，必须介绍一下我最近完成的骄傲之作 —— GaLi-Link。 这是一个能让微信小程序直接读取蓝牙心率设备数据的工具。

📦 GaLi-Link

基于微信小程序低功耗蓝牙 (BLE) 开发，支持标准心率广播协议，实时监测运动状态。

Tech Stack: WeChat MiniProgram, JavaScript, BLE API
→ 在 GitHub 上关注这个项目
