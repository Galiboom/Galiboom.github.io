某教育平台项目

一个面向国际教育企业的全栈网站平台，覆盖前台品牌展示、课程与案例内容、咨询线索收集，以及可维护的后台管理能力。

Next.js 15React 18TypeScriptMySQL + Drizzle

项目做了什么

把教育服务从静态宣传页升级成可持续运营的内容平台。访客可以浏览课程、留学服务、学员案例和新闻资讯，运营人员则可以在后台维护首页区块、文章、课程、案例、轮播图与咨询信息。

品牌与服务展示

首页数据统计、服务项目、优势、录取数据与成功案例组成完整转化路径。

内容管理后台

支持课程、文章、案例、视频、城市办公室和首页配置的增删改查。

咨询线索闭环

前台表单收集咨询需求，后台集中查看和跟进，减少信息遗漏。

中英文体验

公共导航、首页文案与 SEO 信息支持中英文切换，适配国际化受众。

技术记录

项目采用 Next.js App Router 构建，使用 Drizzle ORM 连接 MySQL，NextAuth 负责后台登录，Tailwind CSS 负责响应式界面。部署侧按 Node.js、PM2 与 Nginx 的生产环境组织。

App RouterNextAuthDrizzle ORMTailwind CSSREST APIResponsive UI

项目复盘

这次实现的重点不是堆叠页面，而是把“展示、内容、线索、运营”串成一条可交付的业务链路。前台页面保持清晰的阅读节奏，后台则优先保证日常编辑效率和数据结构的一致性。
