Gali-Player：现代网页音乐播放器项目复盘

一次围绕播放体验、动效细节和暗色毛玻璃 UI 的 React 前端项目练习。

2026 · 05 · 21 React Music Player UI 作品集

Gali-Player 是一个现代网页音乐播放器项目。它不是一个简单的 audio 标签演示，而是围绕「音乐产品界面」做了一套较完整的前端体验： 暗色毛玻璃布局、唱片旋转、音乐波形、播放队列、账号登录演示态、收藏状态、搜索筛选和响应式播放器。

这个项目的重点，是把普通的音乐播放功能包装成一个足够完整、足够有作品集质感的网页应用。

项目定位

Gali-Player 面向的是作品集展示场景。它不追求真实音乐平台的复杂版权和账户体系，而是把重点放在前端 UI 审美、交互细节和基础播放能力上。 用户可以浏览推荐曲目、切换发现页/音乐库/歌单页，也可以登录演示账号，保存本地登录态和收藏状态。

技术栈

React Vite Tailwind CSS v4 Framer Motion Lucide React HTML Audio API LocalStorage Vercel

项目使用 Vite 搭建 React 单页应用，动画层使用 Framer Motion，图标来自 Lucide React。 播放控制基于浏览器原生 HTMLAudioElement，包括播放、暂停、上一首、下一首、随机播放、进度跳转和音量控制。

核心功能

播放控制 支持播放/暂停、上一首、下一首、随机播放、结束自动切歌。
进度与音量 显示当前时间和总时长，可拖动进度条跳转，也可调整音量。
音乐库与搜索 按歌曲、歌手、专辑和心情搜索，并支持音乐库排序。
收藏与歌单 支持收藏/取消收藏歌曲，并在歌单页展示喜欢的音乐。
登录演示态 提供登录弹窗和演示账号，一键登录后展示头像、昵称和邮箱。
视觉动效 唱片旋转、波形动画、页面切换和曲目卡片动效让界面更有生命力。

实现细节

1. HTML Audio API 管理播放

项目通过 useRef 持有 audio 实例，再用 React state 同步当前曲目、播放状态、进度、时长和音量。 当 isPlaying 或 currentIndex 变化时，组件会自动调用 audio 的 play() 或 pause()。

进度条则绑定 currentTime，用户拖动 range input 时直接修改 audio 的播放位置，从而形成即时跳转体验。

2. 数据驱动的曲库

曲目数据集中放在 src/data/tracks.js，每首歌包含标题、歌手、专辑、时长、心情、BPM、主题色、强调色和 MP3 地址。 UI 的背景光效、唱片色彩和曲目卡片状态都可以根据当前歌曲动态变化。

3. Framer Motion 提升切换体验

首页、发现页、音乐库和歌单页通过状态切换渲染，并使用 AnimatePresence 和 motion 做进入/退出动画。 这让页面切换不像普通条件渲染那样生硬，更接近真实产品的流畅感。

4. 登录状态本地保存

登录功能是前端演示版：用户填写昵称、邮箱和密码，或直接使用演示账号登录。 登录后信息会保存到 localStorage，刷新页面也能保持用户状态。正式产品中，这一块可以继续扩展为后端账号、数据库、密码加密和会话管理。

视觉设计

Gali-Player 采用暗色背景、毛玻璃面板、动态氛围光和高饱和主题色。播放器底栏固定在底部，左侧显示当前播放歌曲，中间是播放控制和进度条，右侧是音量控制。 主舞台则承担推荐、发现、曲库和歌单内容。

这套 UI 的重点不是堆功能，而是让每一个播放动作都有反馈：唱片会转、波形会跳、当前歌曲会高亮，卡片 hover 有轻微位移。 对作品集来说，这些细节能更好展示前端交互能力。

部署与上线

项目已经配置了 vercel.json，使用 Vercel 部署。构建命令是 npm run build，输出目录是 dist， 并通过 rewrite 支持单页应用刷新不 404。

可以继续优化的方向

  • 接入真实后端账号体系，同步收藏和播放历史。
  • 将示例 MP3 替换为拥有授权的音乐资源。
  • 增加播放模式：单曲循环、列表循环、播放队列重排。
  • 增加歌词面板、频谱可视化和快捷键控制。
  • 将曲库管理抽象成可配置数据源，方便后续扩展。

总结

Gali-Player 是一个很适合放进作品集的前端项目。它覆盖了组件状态、媒体 API、动效、响应式布局、本地持久化和部署配置等多个点。 虽然业务规模不大，但它能清楚展示一个前端项目从视觉设计到交互实现的完整过程。
