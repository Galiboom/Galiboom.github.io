# Galiboom.github.io

Galiboom 的个人开发日志与作品集，记录 AI Agent、全栈应用、网页游戏和前端实验。

## 本地预览

这是一个无构建依赖的纯静态站点。在仓库目录启动任意静态文件服务器即可：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 文件结构

- `index.html`：主页与作品索引
- `site.css`：全站共享设计系统和响应式样式
- `site.js`：移动端导航、滚动呈现、音乐控制和阅读进度
- `*-*.html`：项目复盘与博客文章
- `gaga.jpg`：站点像素头像
- `music-power.mp3`：可选背景音乐

站点通过 GitHub Pages 发布：[galiboom.github.io](https://galiboom.github.io/)。
